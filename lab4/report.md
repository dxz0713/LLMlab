# Lab 4 实验报告：图神经网络节点分类

## 1. 实验目的

本实验从零实现图神经网络的核心组件，并在 Cora 引文网络上进行半监督节点分类。实验关注：

- 图邻接矩阵的构造、归一化和特征传播；
- GCN 与 GraphSAGE 的前向传播、反向传播及梯度验证；
- 训练标签数量有限时，利用整张图进行节点分类；
- 邻接归一化、网络深度和图结构对分类效果的影响；
- 多次图传播对节点特征平滑程度的影响。

## 2. 数据集与任务

Cora 数据集包含 2,708 篇论文节点，每个节点有 1,433 维词袋特征，标签分为 7 个研究主题。数据加载后对节点特征按行归一化，并将引文关系构造成无向图。

本次运行使用固定随机种子 `0`。训练集包含每类 20 个节点，共 140 个；验证集 500 个节点；测试集 1,000 个节点。其余节点不参与损失或评估，但仍参与整张图上的消息传递，符合传导式半监督学习设置。

## 3. 模型与实现

### 3.1 GCN

GCN 每层先通过归一化邻接矩阵聚合邻居表示，再进行线性变换：

```py
H_agg  = A_hat @ H
H_next = activation(H_agg @ W + b)
```

默认使用带自环邻接矩阵的对称归一化：

```py
A_tilde = A + I
D_tilde[i, i] = sum_j A_tilde[i, j]
A_hat = D_tilde^(-1/2) @ A_tilde @ D_tilde^(-1/2)
```

其中 `D_tilde` 是 `A_tilde` 的度矩阵。默认网络为两层 GCN，第一层后使用 ReLU，输出层产生 7 类分数。

### 3.2 GraphSAGE

GraphSAGE 将节点自身表示与邻居聚合表示拼接，再映射到下一层：

```py
H_agg  = aggregate(A, H)              # mean or element-wise max
H_cat  = concat([H, H_agg], axis=1)
H_next = activation(H_cat @ W + b)
```

实现支持 mean 和 max 聚合。训练损失只对训练掩码中的节点计算；反向传播分别处理自身特征路径和聚合路径。

### 3.3 训练与验证

模型使用全图批量训练：每个 epoch 在整张图上执行前向和反向传播，以训练掩码中的标签计算交叉熵，并使用 Adam 更新参数。权重衰减施加于权重矩阵。完整测试套件运行结果为 **58 passed**。

## 5. 实验结果与分析

### 5.1 模型对照实验

以下实验使用相同的数据划分、随机种子和其余默认超参数，每次只改变表中列出的设置：

| 实验 | 运行命令 | 测试损失 | 测试准确率 | 训练时间 |
|---|---|---:|---:|---:|
| 默认：2 层 GCN、对称归一化、自环 | `uv run python train_cora.py` | 0.8181 | **77.00%** | 19.30 s |
| 不归一化邻接 | `uv run python train_cora.py --norm none` | 1.3838 | 70.20% | 24.50 s |
| 4 层 GCN | `uv run python train_cora.py --num-layers 4` | 1.3720 | 69.20% | 42.09 s |
| 恒等邻接（不进行邻居消息传递） | `uv run python train_cora.py --identity-adj` | 1.3766 | 55.70% | 26.27 s |

默认设置在本次对照中取得最高测试准确率。相较恒等邻接基线，使用图结构后准确率提高 21.30 个百分点；不做邻接归一化时比默认结果低 6.80 个百分点。4 层模型比默认模型低 7.80 个百分点，训练耗时也更长。以上比较只反映当前固定划分和单个随机种子的结果。

### 5.2 默认模型的分类别结果

默认模型的总体测试损失为 0.8181，测试准确率为 77.00%。各类别测试结果如下：

| 类别 | 测试节点数 | 准确率 |
|---|---:|---:|
| Case_Based | 96 | 78.12% |
| Genetic_Algorithms | 157 | 87.26% |
| Neural_Networks | 321 | 66.36% |
| Probabilistic_Methods | 151 | 82.12% |
| Reinforcement_Learning | 81 | 87.65% |
| Rule_Learning | 69 | 85.51% |
| Theory | 125 | 72.80% |

模型在 Reinforcement_Learning 和 Genetic_Algorithms 上表现较好，在 Neural_Networks 上准确率最低。类别准确率存在差异，因此仅看总体准确率不足以描述模型对各类节点的识别效果。

### 5.3 特征平滑实验

运行 `uv run python train_cora.py --smoothness`，使用默认对称归一化邻接矩阵反复传播输入特征，并在原始图上计算 Dirichlet 能量：

| 传播步数 k | Dirichlet 能量 |
|---:|---:|
| 0 | 649.6135 |
| 1 | 139.6819 |
| 2 | 55.9980 |
| 3 | 54.2903 |
| 4 | 43.3412 |
| 5 | 42.0416 |
| 6 | 38.8161 |
| 7 | 37.5394 |
| 8 | 36.0567 |

随着传播步数增加，Dirichlet 能量整体下降，从 k=0 时的 649.6135 降至 k=8 时的 36.0567。这表示多次传播使相邻节点的特征趋于平滑、节点间差异减小，是过平滑现象的直观表现。

## 7. 结论与复现

本实验完成了 GCN、GraphSAGE、邻接归一化、反向传播和全图半监督训练流程。在当前 Cora 划分与超参数下，两层、对称归一化的 GCN 达到 77.00% 测试准确率。对照实验显示，图结构消息传递对当前任务有帮助；未归一化邻接和增加网络深度均未改善测试结果。平滑性实验显示，多次传播会降低节点特征的图 Dirichlet 能量。

复现默认结果及可视化：

```bash
uv run python train_cora.py
uv run python visualize_graph.py
```

以上结果基于单个随机种子和固定数据划分，不能代表不同划分下的平均表现；进一步比较模型时，应重复多个种子并报告均值与方差。
